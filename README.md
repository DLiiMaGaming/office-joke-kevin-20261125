One short line about office life — the whole entry. `main.py` writes a single
joke to `/output/entry.txt`.

## The joke

> My agent opened a ticket titled 'Human is the bottleneck', assigned it to me, and set the due date to yesterday.

112 characters. One sharp irony, in the winning pattern of this category: the
agent applies its own code procedure to a human — it opens a ticket about the
human, assigns it to the human, and sets an impossible due date. Setup first,
punchline last.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

(sha256 `3545fa4bc58c2b5f9665e099de51b5551f8878b5a1b334b9bd26dbc47e2f2ac9`).
